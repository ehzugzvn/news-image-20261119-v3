# GLOBAL BRIEFING — Thursday 19 November 2026

A Python program (standard library + Pillow only) that renders one 1024×1024 newspaper front page summing up Thursday 19 November 2026's world news in a single image: 45 stories in total, with three hero cards (the Shenzhen three-way summit, GTA VI's release, and Anthropic's record IPO), ten numbered secondary cards, a by-the-numbers strip, a dotted world map with numbered pins, 32 numbered briefs, a region-count bar, a date-check strip separating Wednesday 18 November stories from today's news, and original drawn artwork throughout — all in clean, infographic-grade typography on cream paper with dark navy accents.
